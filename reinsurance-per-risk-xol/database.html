Module 03 — Loss Database

Per-Risk XoL — Loss Database

Per-risk layers are pierced by single large losses — one fire, one platform, one liability judgment. These are the kinds of loss that define working and higher risk-XL layers.

Reading the database A per-risk layer cares about severity per risk, not accumulation across risks. The same event that is a catastrophe for the cat programme may be a series of separate per-risk losses here — which is exactly why the Contract & Wordings module is careful about the occurrence definition and about not double-counting the same loss against both towers.
